Now the idea makes sense.

Most connections can remain local while a single long-range link can create a shortcut between distant parts of a network. But a shortcut only matters if it actually changes the route being tested. Sometimes there simply isn't a useful long-range shortcut for the chosen pair.

Behind the animation

Shortest paths are calculated with Breadth-First Search (BFS). The simulator tests every eligible long-range connection and only accepts one if it genuinely reduces the selected pair's shortest-path distance.
