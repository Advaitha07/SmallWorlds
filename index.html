Now the small-world idea makes sense.

A food web can have mostly local feeding relationships. A new link between distant parts of the network can create a shortcut, reducing shortest-path distances beyond just the two organisms it directly joins. That is the mechanism we are illustrating. It is a network experiment, not a claim that real ecosystems universally have small-world structure.

Behind the animation

Food-web paths are directional, so the route is calculated with Breadth-First Search (BFS) following resource → consumer arrows. To find a shortcut, the simulator tests candidate feeding links that are absent, trophically plausible within this toy model, and topologically distant in the original web. It keeps one only when it genuinely reduces the selected pair's shortest-path distance.
